## Priorities after this release candidate

1. Run the opt-in live integration test separately with at least two authorized providers. Exercise OpenRouter's real browser redirect flow. Do not claim verified live connections until these pass.
2. Harden public-service identity, password recovery/MFA, parser isolation, managed KMS and operational backup/monitoring. Validate the container and TLS/scanner deployment in its target environment.
3. Finish localization and screen-reader audits; expand format ingestion with separate bounded parser pipelines, starting with OCR and structured PDF extraction.
4. Complete timed/multi-format exams and full source-heading coverage verification, then introduce tested diagnostic learning flows.
5. Extend the implemented text slide decks/HTML export with richer slide editing, PPTX export and illustrations; add real TTS/audio, infographics and narrated video with separate provider consent, quotas and exports.
6. Add sharing and cross-device collaborative updates after a fresh authorization review; scale storage/retrieval as measured usage warrants it.
